# Arsip sementara — kode SPA lama

Folder ini **bukan bagian dari aplikasi**. Tidak ada yang mengimpornya, tidak
ikut di-build, dan tidak dilayani oleh server mana pun.

Isinya tinggal `src/` dari dua aplikasi React yang berdiri sendiri sebelum
proyek dipadukan menjadi monolit Inertia — dipertahankan semata sebagai sumber
saat memindahkan halaman yang tersisa. Seluruh `node_modules/`, `dist/`, dan
berkas konfigurasinya sudah dihapus; padanannya kini ada di root proyek.

Halaman yang sudah dipindah ada di `resources/js/Pages/`. Daftar yang belum,
beserta urutannya, ada di `docs/MIGRASI-MONOLIT.md`.

**Hapus seluruh folder ini setelah Fase 4 selesai** — lihat daftar periksa
Fase 5 pada dokumen tersebut.
